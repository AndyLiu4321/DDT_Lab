# 固定 0.35 m 高度的 PACE 平地训练

任务：`DDT-Velocity-Flat-Andy-Pace-Fixed035-v0`。
配置：`flat_env_cfg.py`；在 AndyFlatEnvCfg 派生链上复用 PACE 执行器及零命令奖励。
独立实验目录：`logs/np3o/andy_pace_fixed035/`。从头训练，不加载旧高度策略。

## 任务与部署输入

仍可给前进速度和转向命令，目标高度固定为 0.35 m（奖励目标，不锁定根位置）。
50% 命令段为 vx=wz=0；保留零命令的平移、转向、关节运动惩罚，
另奖励零命令时保持直立和 0.35 m 高度。移除随高度变化的腿角引导和低高度接触模式。

观测维度维持 27、历史 10×27、动作 6。命令槽仍为 `[vx, 0.35, wz]`，
输入缩放后为 `[2*vx, 1.75, .25*wz]`。第二槽只为接口兼容保留，部署不得改为 vy 或动态高度。
轮子相对位置槽保持零。动作尺度仍为 `[.15,.66,10,.15,.66,10]`。

## 控制时序

- 物理 1 ms / 1000 Hz。
- 有效 PD 力矩输出每 5 步采样更新 / 200 Hz，其间保持。
- 策略每 20 步更新 / 50 Hz，10 帧历史仍覆盖约 0.2 秒。
- 新 SampledPaceDCMotor 在每个环境 reset 后立即刷新首个力矩样本，
  并独立重置相位；额外力矩延迟缓冲按 1 ms 步推进。
- 旧 PACE Height/Robust 任务仍是 1000 Hz 物理、每物理步更新 PD、50 Hz 策略。
- 当前 rl_sar MuJoCo 默认物理 2 ms，5 ms 控制期限被量化到 4/6 ms 间隔；
  对照此新任务时用 `--dt .001`，并同步新策略的 PACE 坐标/动力学配置。

## 域随机化范围

这些是训练假设，尚不是实机测得的参数置信区间。基准是 PACE 最优候选。

| 项目 | 范围/时机 |
| --- | --- |
| PD 增益 | ±20%，reset |
| 关节摩擦（静/动/黏性） | ×0.6–1.4，startup |
| armature | ×0.75–1.25，startup |
| 基座质量 | ±15%，startup |
| 基座质心 | 各轴 ±1 cm，startup |
| 各刚体惯量 | ±15%，startup |
| 接触静/动摩擦 | 0.4–1.2 / 0.3–1.0，startup，动摩擦≤静摩擦 |
| 恢复系数 | 0–0.1，startup |
| 电机出力系数 | 0.8–1.0，reset，每执行器组每环境独立 |
| 额外力矩延迟 | 0–5 ms 整数步，reset，每执行器组每环境独立 |
| 初始关节位置/速度 | ±0.08 rad / ±0.2 rad/s |
| 初始横滚/俯仰 | ±0.08 rad |
| Actor 观测噪声 | 角速度 ±0.2；重力投影 ±0.04；关节角 ±0.01；关节速度 ±0.5 |
| 推扰 | 每 5–10 秒，性能门槛课程，从零到 XY 每轴 ±0.2 m/s |

Critic 无观测噪声；编码器偏差固定，避免同时改变坐标约定。
原有根速度/位置随机初始化保留。Play 版本使用标称动力学，无额外延迟、出力衰减及推扰，
仍采用 1000/200/50 Hz 时序；训练版本用于随机化压力测试。

固定高度任务的键盘高度上下界都是 0.35。正式部署前需要验证固定高度跟踪、零命令漂移、
力矩饱和与受扰恢复；增加随机化不能替代这些测试。
